### Tom Jaejoon Lee

**Creator of [ClawSouls](https://clawsouls.ai)** — an open-spec platform for portable AI agent personas.

I work on the identity layer for AI agents: a persona you write once as a file, carry across models and runtimes, and keep consistent over long sessions. The spec is open, and I build the tooling around it.
