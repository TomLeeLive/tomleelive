### 💡 Philosophy

> "The best tools are the ones that disappear — they let you focus on the problem, not the process."

I believe in:

- **Ship first, polish later** — Working software beats perfect plans
- **Small commits, clean history** — Every commit tells a story
- **Systematic debugging** — Reproduce → Isolate → Fix → Verify. No guessing.
- **Docs as first-class citizens** — If it's not documented, it doesn't exist
- **Open source by default** — Share what you build, learn from what others share
